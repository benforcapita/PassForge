# PassForge Design System

The PassForge desktop UI is built on the **Obsidian Precision** design system (dark only).

- `passforge_design_system_specification.md` — **canonical reference.** Color tokens, type scale, layout measurements, component specs, iconography, states, motion, accessibility, and copy guidelines live here. When in doubt, follow this document.
- `obsidian_precision/DESIGN.md` — earlier design variant. Kept for reference only; where it conflicts with the specification, the specification wins.
- `passforge_master_key_authorization/` — lock screen mockup (`screen.png` + `code.html`).
- `passforge_vault_workbench/` — main workbench mockup (`screen.png` + `code.html`).

The mockups illustrate layout and density. Features shown in mockups that are not backed by the desktop backend (e.g. entropy telemetry, batch synthesis, sync/export, biometric unlock) are **not** implemented; the UI only surfaces real data.
